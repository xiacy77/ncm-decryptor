# 蓝毛小女仆 pet asset

`maid-idle.webp` / `maid-idle.png` are derived from the **蓝毛小女仆 / Blue-Haired Little Maid**
desktop-pet project:

- Source: <https://github.com/12we21/cute-fat-fish-pet>
- npm package used for the source animation: `@tuweizhi/dsh-pet`
- Original pet: **cute-fat-fish-pet**, by **Mikolu**, with thanks to
  **PC2005-cloud / dsh-pet 0.3.0**
- License: MIT (see `LICENSE.txt`)

For this static anniversary site, the source idle animation
`待机呼吸休闲.webm` was sampled, background-keyed, cropped, and re-exported as a
transparent animated WebP plus a PNG fallback. No other changes were made to the
character design.

The character and animation remain the work of the original authors; this project
only includes a small adapted copy for personal, non-commercial use. Keep the
included MIT license and attribution when redistributing.
